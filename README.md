# Login-Form-110

A clean, minimal login form built with HTML, CSS and a bit of JavaScript.

![Login Form Screenshot](./Screenshot%202024-08-11%20000822.png)

## Overview

This repository contains a simple, responsive login form demonstration. It's intended as a small UI project to practice layout, styling, and basic client-side interactivity.

## Features

- Clean, focused login UI
- Responsive layout that works on desktop and mobile
- Styled using CSS (no frameworks)
- Small JavaScript for interactive behavior (if present)

## Files

- `index.html` — The login page markup
- `style.css` — Styles for the form and page
- `Screenshot 2024-08-11 000822.png` — Screenshot used in this README
- `anime-moon-landscape (3).jpg` — Background/asset image included in the repo

## How to use

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-110.git

2. Open `index.html` in your web browser (double-click or serve with a static server).

That's it — the page should load and display the login form.

## Customize

- Edit `style.css` to change colors, spacing, and responsive breakpoints.
- Edit `index.html` to add or remove fields.
- Add more JavaScript for form validation or to hook into a backend.
